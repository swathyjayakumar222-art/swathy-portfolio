# Swathy Jayakumar — Portfolio

A responsive portfolio website for Swathy Jayakumar, B.Tech Information Technology student at NIT Jalandhar.

## Deploy with GitHub Pages
1. Open Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select `main` and `/ (root)`, then Save.
4. Your site will publish at `https://swathyjayakumar222-art.github.io/swathy-portfolio/`.
